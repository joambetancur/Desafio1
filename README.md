## Descripción
Este repositorio contiene el desarrollo del primer desafío del curso, centrado en la implementacion de un sistema de bits para un juego de Tetris. 

## Contenido
* **Desafio1.docx**: Archivo editado con los commits.
* **Desafio1.pdf**: Versión de lectura en Github.
* **main.cpp**: Archivo principal, encargado de pedirle los datos al usuario y mostrar resultados.
* **tablero.h**: Donde se definen las funciones.
* **tablero.cpp**: Archivo donde esta la logica para el espacio en memoria y como dibujar el tablero.
